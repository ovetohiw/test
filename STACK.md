# Архитектура

- [ ] Монолит.
- [ ] Микросервис.


## Языки

- [ ] TypeScript — JavaScript со статической типизацией: ошибки типов видны до запуска.
- [ ] JavaScript — язык браузера и Node без обязательной компиляции типов.
- [ ] Python — язык скриптов, API и данных с коротким кодом и богатой экосистемой.
- [ ] Go — компилируемый язык для быстрых сетевых сервисов и простых бинарников.
- [ ] Rust — язык без сборщика мусора: память контролируется на этапе компиляции.
- [ ] Java — язык JVM для крупных серверных систем и долгой поддержки.
- [ ] Kotlin — современный язык JVM, совместимый с Java и удобный для Android.
- [ ] C# — язык .NET для веб-сервисов, десктопа и игр на одной платформе.
- [ ] PHP — язык серверных страниц и веб-приложений, основа WordPress и Laravel.
- [ ] Ruby — выразительный язык, чаще всего с фреймворком Rails.
- [ ] Swift — основной язык приложений Apple: iOS, macOS и SwiftUI.
- [ ] Dart — язык Flutter: один код для мобильных, веба и десктопа.

## Frontend / UI

- [ ] React — библиотека UI на компонентах, без роутинга и сборки приложения из коробки.
- [ ] Next.js — фреймворк React: роутинг, серверный рендер и API в одном проекте.
- [ ] Vue — библиотека UI с шаблонами в разметке, без обязательного фреймворка вокруг.
- [ ] Nuxt — фреймворк Vue: роутинг, SSR и структура приложения из коробки.
- [ ] Svelte — компилятор UI: реактивность в языке, почти без рантайма в браузере.
- [ ] SvelteKit — фреймворк Svelte: роутинг, серверный рендер и загрузка данных.
- [ ] Angular — полный фреймворк: модули, DI, роутинг и формы в одном комплекте.
- [ ] Solid — библиотека UI с мелкими обновлениями DOM без виртуального дерева React.
- [ ] Astro — сайты из островов: страницы статичны, JS подключается только где нужен.
- [ ] Remix — фреймворк React вокруг веб-стандартов: формы, загрузчики и вложенные маршруты.
- [ ] HTMX — HTML-атрибуты вместо SPA: сервер отдаёт фрагменты разметки по запросу.

## Стилизация UI

- [ ] Tailwind CSS — утилитарные классы в разметке, без отдельных файлов стилей на компонент.
- [ ] CSS Modules — обычный CSS, классы автоматически локальны для файла компонента.
- [ ] Styled Components — CSS внутри JS через шаблонные строки, стили привязаны к компоненту React.
- [ ] Emotion — CSS-in-JS как Styled Components, с упором на производительность и css-проп.
- [ ] Sass — надстройка над CSS: переменные, вложенность и примеси до компиляции в CSS.
- [ ] shadcn/ui — копируемые компоненты React на Tailwind, код остаётся в вашем репозитории.
- [ ] MUI — готовая библиотека компонентов React в стиле Material Design.
- [ ] Ant Design — набор компонентов React для плотных админок и таблиц.
- [ ] Chakra UI — компоненты React со стилями через пропы, без отдельных CSS-файлов.
- [ ] Bootstrap — сеточная система и готовые классы CSS, не привязаны к фреймворку.

## Mobile

- [ ] React Native — нативные экраны iOS и Android на компонентах React, без веб-вью.
- [ ] Expo — обвязка React Native: сборка, камера и пуш без ручной настройки Xcode и Gradle.
- [ ] Flutter — приложения на Dart: свой движок отрисовки, один код на несколько платформ.
- [ ] SwiftUI — декларативный UI только для платформ Apple, на языке Swift.
- [ ] Kotlin Multiplatform — общий код на Kotlin, нативный UI каждой платформы остаётся своим.
- [ ] Ionic — мобильный UI из веб-компонентов, приложение крутится внутри веб-вью.
- [ ] Capacitor — упаковка веб-приложения в нативную оболочку с доступом к API устройства.

## Backend / API

- [ ] Express — минимальный HTTP-сервер Node: маршруты собираете сами, модулей из коробки нет.
- [ ] Fastify — HTTP-сервер Node быстрее Express, со схемой запроса и плагинами.
- [ ] NestJS — фреймворк Node с модулями и DI, чаще всего поверх Express или Fastify.
- [ ] Next.js API / Route Handlers — серверные эндпоинты внутри проекта Next.js, без отдельного сервера.
- [ ] Django — полный фреймворк Python: админка, ORM, пользователи и маршруты в комплекте.
- [ ] FastAPI — API на Python со схемами типов и автоматической OpenAPI-документацией.
- [ ] Flask — минимальный веб-фреймворк Python: ядро маленькое, остальное подключаете сами.
- [ ] Spring Boot — фреймворк Java с DI, автоконфигурацией и готовыми стартерами модулей.
- [ ] ASP.NET — веб-фреймворк .NET для API и страниц на C#.
- [ ] Laravel — полный фреймворк PHP: ORM, очереди, миграции и шаблоны из коробки.
- [ ] Ruby on Rails — фреймворк Ruby «соглашения вместо настройки»: модели, маршруты и миграции.
- [ ] Gin — лёгкий HTTP-роутер Go, аналог Express по минимализму.
- [ ] Echo — HTTP-фреймворк Go с роутером и middleware, чуть богаче Gin из коробки.
- [ ] Actix — быстрый веб-фреймворк Rust на акторах, для высоконагруженных API.

## API-стиль

- [ ] REST — ресурсы по URL и глаголам HTTP, клиент запрашивает заранее известные эндпоинты.
- [ ] GraphQL (Apollo) — один эндпоинт, клиент выбирает поля; Apollo даёт сервер, кэш и клиент.
- [ ] GraphQL (Yoga) — сервер GraphQL без платформы Apollo, схема и резолверы в вашем коде.
- [ ] tRPC — вызов серверных функций как обычных, типы общие, без отдельной схемы API.
- [ ] gRPC — бинарные вызовы по контракту protobuf, удобно между сервисами, не для браузера напрямую.
- [ ] WebSocket — постоянное двустороннее соединение: сервер и клиент шлют сообщения в любой момент.
- [ ] SSE — сервер пушит поток событий в браузер по обычному HTTP, клиент назад не пишет.

## Базы данных

- [ ] PostgreSQL — реляционная БД с транзакциями, JSON и расширениями, основной выбор для новых сервисов.
- [ ] MySQL — реляционная БД, широко стоит на хостингах, диалект SQL отличается от PostgreSQL.
- [ ] MariaDB — форк MySQL с совместимым протоколом и своими движками хранения.
- [ ] SQLite — файл базы на диске, без отдельного сервера, удобно для локалки и маленьких приложений.
- [ ] MongoDB — документная БД: записи как JSON, схема гибкая, транзакции ограничены.
- [ ] Redis — память-хранилище ключ-значение: кэш, сессии, счётчики и короткие очереди.
- [ ] Elasticsearch — поиск по тексту и агрегации, не замена основной транзакционной БД.
- [ ] ClickHouse — колоночная БД для аналитических запросов по большим таблицам событий.
- [ ] DynamoDB — облачная ключ-значение БД AWS, масштаб без своего сервера.
- [ ] Supabase — Postgres и auth как сервис, с клиентским SDK и политиками доступа.
- [ ] Firebase — BaaS Google: документы Firestore, auth и хостинг без своего сервера БД.

## ORM / доступ к данным

- [ ] Prisma — ORM для TypeScript: схема в своём файле, клиент и миграции генерируются.
- [ ] Drizzle — тонкий SQL-слой для TypeScript: запросы похожи на SQL, без тяжёлого рантайма.
- [ ] TypeORM — ORM для TypeScript через декораторы классов, сущности живут в коде.
- [ ] Sequelize — зрелый ORM Node с моделями на JS-объектах, без обязательного TypeScript.
- [ ] SQLAlchemy — ORM и конструктор SQL для Python, стандарт рядом с Flask и часто с FastAPI.
- [ ] Entity Framework — ORM .NET: модели C# отображаются на таблицы, миграции в комплекте.
- [ ] Hibernate — ORM Java: объекты отображаются на таблицы, обычно через Spring Data.
- [ ] Diesel — ORM Rust со схемами, проверяемыми компилятором, запросы типобезопасны.

## Auth

- [ ] Auth.js / NextAuth — библиотека сессий и OAuth внутри Next.js и других JS-приложений.
- [ ] Clerk — готовый сервис входа: виджеты, пользователи и сессии, свой код логина не пишете.
- [ ] Supabase Auth — вход пользователей в проекте Supabase, рядом с его Postgres.
- [ ] Firebase Auth — вход через аккаунт Google Firebase, токены проверяет их SDK.
- [ ] Keycloak — свой сервер единого входа: логин, роли и OIDC, данные пользователей у вас.
- [ ] Auth0 — облачный сервис входа и соцсетей, правила доступа настраиваются у них.
- [ ] Passport — набор стратегий логина для Node, сессию и хранение пользователей пишете сами.
- [ ] JWT (свой) — токены подписываете сами, без отдельного сервиса и без готовых экранов входа.
- [ ] OAuth2 / OIDC — протоколы «войти через провайдера», а не готовый продукт: нужен клиент и сервер.

## Очереди / фон

- [ ] BullMQ — очереди задач в Node поверх Redis: повторы, задержки и воркеры в процессе.
- [ ] RabbitMQ — брокер сообщений: обменники и очереди между разными сервисами и языками.
- [ ] Kafka — журнал событий на диске: много потребителей читают один поток, не разовая задача.
- [ ] Celery — фоновые задачи Python, брокер обычно Redis или RabbitMQ.
- [ ] Sidekiq — фоновые задачи Ruby на Redis, типичный спутник Rails.
- [ ] Temporal — оркестратор долгих процессов: шаги, таймеры и повтор при падении воркера.
- [ ] AWS SQS — очередь сообщений как сервис AWS, без своего брокера.

## Хранилище файлов

- [ ] S3 — объектное хранилище AWS: файлы по ключу, доступ через API, не через диск сервера.
- [ ] MinIO — свой S3-совместимый сервер: тот же API, данные лежат у вас.
- [ ] Cloudinary — облако картинок и видео: загрузка, ресайз и отдача по URL.
- [ ] Локальная ФС — файлы в папке сервера, без внешнего хранилища и без масштаба на несколько машин.

## Тесты

- [ ] Vitest — быстрый тест-раннер для Vite и TypeScript, API похож на Jest.
- [ ] Jest — тест-раннер JavaScript с моками и снапшотами, часто без Vite.
- [ ] Playwright — браузерные тесты сценариев: клики и страницы в Chromium, Firefox и WebKit.
- [ ] Cypress — браузерные тесты в своём раннере, сценарии пишутся как цепочка команд.
- [ ] pytest — тест-раннер Python: функции-тесты, фикстуры и плагины.
- [ ] JUnit — каркас модульных тестов для Java и Kotlin.
- [ ] Testing Library — проверка UI с точки зрения пользователя, без привязки к внутренностям компонента.
- [ ] k6 — нагрузочные скрипты: сколько запросов сервис держит, не проверка вёрстки.

## Качество кода

- [ ] ESLint — поиск ошибок и спорных конструкций в JavaScript и TypeScript.
- [ ] Prettier — автоформат отступов и кавычек, без поиска багов в логике.
- [ ] Ruff — быстрый линтер и часть формата для Python, замена Flake8 и isort.
- [ ] Black — форматтер Python с почти нулевыми настройками стиля.
- [ ] Biome — один инструмент для линта и формата JS/TS, альтернатива связке ESLint и Prettier.
- [ ] Husky — git-хуки: проверки запускаются перед коммитом, сами правила лежат в других инструментах.
- [ ] lint-staged — гоняет линтер только по файлам в коммите, а не по всему репозиторию.

## Сборка / пакеты

- [ ] Vite — сборщик фронтенда: быстрый dev-сервер и бандл для продакшена.
- [ ] Webpack — сборщик модулей с гибкими лоадерами, тяжелее в настройке, чем Vite.
- [ ] Turborepo — кэш и порядок задач в монорепо JS, сами пакеты ставит pnpm или npm.
- [ ] Nx — монорепо с графом проектов, генераторами и кэшем сборки, шире чем только JS.
- [ ] pnpm — менеджер пакетов Node: общее хранилище на диске и строгие зависимости.
- [ ] npm — менеджер пакетов, идёт вместе с Node, без отдельной установки.
- [ ] yarn — менеджер пакетов Node, альтернатива npm с собственным локфайлом.
- [ ] Docker — образ приложения со всеми зависимостями, одинаковый запуск на любой машине.
- [ ] Poetry — зависимости и виртуальное окружение Python через pyproject.toml.
- [ ] uv — быстрый установщик пакетов Python, может заменить pip и Poetry.

## CI/CD

- [ ] GitHub Actions — пайплайны в репозитории GitHub: тесты и деплой по пушу.
- [ ] GitLab CI — пайплайны в GitLab, конфиг в файле репозитория.
- [ ] CircleCI — отдельный сервис сборки, подключается к GitHub или GitLab.

## Хостинг / cloud

- [ ] Vercel — хостинг фронтенда и Next.js, деплой из git, функции по запросу.
- [ ] Netlify — хостинг статики и простых серверных функций, деплой из git.
- [ ] AWS — набор сервисов Amazon: машины, базы, очереди и хранилища собираете сами.
- [ ] GCP — облако Google: машины, Cloud Run и базы, аналогично AWS по роли.
- [ ] Azure — облако Microsoft, удобно рядом с .NET и корпоративным входом.
- [ ] Railway — простой хостинг сервисов и Postgres из репозитория, без сборки своего облака.
- [ ] Fly.io — контейнеры близко к пользователю, приложение в Docker на их машинах.
- [ ] Render — хостинг веба, воркеров и Postgres, деплой из git без своего кластера.
- [ ] Docker Compose — несколько контейнеров на одной машине по одному файлу, не оркестратор кластера.
- [ ] Kubernetes — оркестратор многих машин: выкат, масштаб и перезапуск контейнеров.

## Наблюдаемость

- [ ] OpenTelemetry — единый сбор трейсов, метрик и логов, сами дашборды рисует другая система.
- [ ] Sentry — ошибки и стеки в проде, не замена метрик нагрузки.
- [ ] Datadog — платформа целиком: метрики, логи, трейсы и алерты в одном облаке.
- [ ] Prometheus — сбор числовых метрик с сервисов и правила алертов, графики обычно снаружи.
- [ ] Grafana — дашборды поверх Prometheus, Loki и других источников, сама метрики не хранит.
- [ ] Loki — хранилище логов, запросы в том же стиле, что у Prometheus, просмотр в Grafana.

## Документация API

- [ ] OpenAPI / Swagger — спецификация эндпоинтов в YAML или JSON и UI, где можно вызвать метод.
- [ ] Stoplight — редактор и портал вокруг OpenAPI: дизайн контракта до кода.
- [ ] Redoc — статическая страница документации из готового файла OpenAPI, без конструктора.
