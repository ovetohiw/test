# Активные планы

Создайте папку и держите два markdown-файла на каждый активный exec plan в этой папке. Первый файл является планом общим, второй является декомпозицией.

Рекомендуемый шаблон имени файла:

- `YYYY-MM-DD-short-topic` - папка для планов
- `YYYY-MM-DD-short-topic-plan.md` - общий план
- `YYYY-MM-DD-short-topic-decompoze.md` - декомпозиция

Каждый активный план должен быть достаточно актуален, чтобы свежая сессия агента
могла продолжить работу, опираясь только на репозиторий.
